# GAME PROPOSAL

## Game Title

Neon Rush – An endless 3D-style rolling ball game inspired by Slope.

## Main Goal

The player's goal is to control a rolling ball down a fast-moving neon track, avoid obstacles, stay on the platform, and survive for as long as possible.

## Player Controls

- Left Arrow / A: Move left.
- Right Arrow / D: Move right.
- Spacebar: Start or restart the game.

## Gameplay

- The ball automatically rolls forward.
- The track contains obstacles, gaps, and barriers.
- The player must move left and right to avoid obstacles.
- The game gradually becomes faster and more challenging.
- The player must stay on the track without falling.

## Scoring

- Players earn points based on the distance they travel.
- The longer they survive, the higher their score.
- A high-score system saves the player's best result using browser local storage.

## Win/Lose Rules

- Win: There is no final ending. The objective is to achieve the highest score possible.
- Lose: The game ends when the ball hits an obstacle or falls off the track.
- Players can restart and try to beat their previous high score.

## First Version

The first version will include:

- A rolling ball.
- A 3D-style neon track.
- Left and right movement.
- Basic obstacles.
- Increasing game speed.
- Score and high-score display.
- Game-over and restart screens.
- Keyboard controls.

The game will be developed using HTML, CSS, and JavaScript and hosted on GitHub Pages. It will not require a backend, database, login, or paid services.
